ReproductiveNumbers.jl

Next-generation matrices and reproduction numbers for compartmental epidemic models written with ModelingToolkit.jl or Catalyst.jl, computed symbolically where a closed form exists and numerically otherwise.

The construction follows Diekmann, Heesterbeek and Roberts (2010), The construction of next-generation matrices for compartmental epidemic models, J. R. Soc. Interface 7:873–885 (doi:10.1098/rsif.2009.0386). See Mathematical background for the recipe and Tutorial for a worked introduction.

Installation

using Pkg
Pkg.add(url = "https://github.com/epirecipes/ReproductiveNumbers.jl")

A first example

using ReproductiveNumbers, ModelingToolkit
using ModelingToolkit: t_nounits as t, D_nounits as D

@parameters β σ γ μ N
@variables S(t) E(t) I(t) R(t)
eqs = [D(S) ~ μ * N - β * S * I / N - μ * S,
    D(E) ~ β * S * I / N - (σ + μ) * E,
    D(I) ~ σ * E - (γ + μ) * I,
    D(R) ~ γ * I - μ * R]
seir = complete(System(eqs, t; name = :seir))

ngm = next_generation_matrix(seir, [E, I])

\[\begin{aligned} x = \left[ \begin{array}{c} E\left( t \right) \\ I\left( t \right) \\ \end{array} \right] \\ T = \left[ \begin{array}{cc} 0 & \beta \\ 0 & 0 \\ \end{array} \right] \\ \Sigma = \left[ \begin{array}{cc} - \mu - \sigma & 0 \\ \sigma & - \gamma - \mu \\ \end{array} \right] \\ K = \left[ \begin{array}{c} \frac{\beta ~ \sigma}{\left( \gamma + \mu \right) ~ \left( \mu + \sigma \right)} \\ \end{array} \right] \quad \text{indexed by } \left[ \begin{array}{c} E\left( t \right) \\ \end{array} \right] \\ R_0 = \frac{\beta ~ \sigma}{\left( \gamma + \mu \right) ~ \left( \mu + \sigma \right)} \end{aligned}\]

basic_reproduction_number(ngm)

\[ \begin{equation} \frac{\beta ~ \sigma}{\left( \gamma + \mu \right) ~ \left( \mu + \sigma \right)} \end{equation} \]

basic_reproduction_number(ngm, Dict(β => 0.5, σ => 0.25, γ => 0.2, μ => 0.01, N => 1e3))
2.2893772893772892

What the package provides

  • next_generation_matrix splits the linearised infected subsystem into a transmission matrix T and a transition matrix Σ, and builds the next-generation matrix with large domain K_L = -TΣ⁻¹ and its restriction K to the states-at-infection. The infection-free steady state is found automatically when it is unique and can be supplied otherwise. The classification of terms (or, for Catalyst, reactions) as transmissions can be overridden, see Choosing what counts as a transmission.
  • basic_reproduction_number returns R₀ in closed form when the next-generation matrix decomposes into irreducible blocks that are 1 × 1, rank one or 2 × 2, and otherwise throws a NoClosedFormError; with parameter values it always returns a number.
  • type_reproduction_number, small_domain_matrix, characteristic_polynomial, spectral_radius, validate_decomposition and evaluate for further analysis.
