Tutorial

This tutorial builds a next-generation matrix step by step, first from a ModelingToolkit system and then from a Catalyst reaction network, and shows what to do when no closed form exists. The Vignettes go further on each topic.

A ModelingToolkit model

We use an SEIR model with births and deaths, so that the infection-free steady state is unique.

using ReproductiveNumbers, ModelingToolkit, Symbolics, LinearAlgebra
using ModelingToolkit: t_nounits as t, D_nounits as D

@parameters β σ γ μ N
@variables S(t) E(t) I(t) R(t)
eqs = [D(S) ~ μ * N - β * S * I / N - μ * S,
    D(E) ~ β * S * I / N - (σ + μ) * E,
    D(I) ~ σ * E - (γ + μ) * I,
    D(R) ~ γ * I - μ * R]
seir = complete(System(eqs, t; name = :seir))

Which states are infected?

You tell the package which unknowns are infected compartments, as symbolic variables or as Symbols. Their order fixes the rows and columns of T, Σ and K_L.

sub = infected_subsystem(seir, [E, I])
sub.f_infected

\[ \begin{equation} \left[ \begin{array}{c} \frac{I\left( t \right) ~ S\left( t \right) ~ \beta}{N} - E\left( t \right) ~ \left( \mu + \sigma \right) \\ E\left( t \right) ~ \sigma - I\left( t \right) ~ \left( \gamma + \mu \right) \\ \end{array} \right] \end{equation} \]

The infection-free steady state

Setting the infected states to zero and solving the remaining equations:

disease_free_equilibrium(seir, [E, I])
Dict{Num, Any} with 4 entries:
  R(t) => 0
  E(t) => 0
  I(t) => 0
  S(t) => N

If the steady state is not unique (an SIR model without demography, say), pass it with the equilibrium keyword. Any state is accepted, which gives a reproduction number at that state rather than the basic one.

Transmissions, transitions and the next-generation matrices

ngm = next_generation_matrix(seir, [E, I])

\[\begin{aligned} x = \left[ \begin{array}{c} E\left( t \right) \\ I\left( t \right) \\ \end{array} \right] \\ T = \left[ \begin{array}{cc} 0 & \beta \\ 0 & 0 \\ \end{array} \right] \\ \Sigma = \left[ \begin{array}{cc} - \mu - \sigma & 0 \\ \sigma & - \gamma - \mu \\ \end{array} \right] \\ K = \left[ \begin{array}{c} \frac{\beta ~ \sigma}{\left( \gamma + \mu \right) ~ \left( \mu + \sigma \right)} \\ \end{array} \right] \quad \text{indexed by } \left[ \begin{array}{c} E\left( t \right) \\ \end{array} \right] \\ R_0 = \frac{\beta ~ \sigma}{\left( \gamma + \mu \right) ~ \left( \mu + \sigma \right)} \end{aligned}\]

The object holds everything:

T, Σ = transmission_transition_matrices(ngm)
T

\[ \begin{equation} \left[ \begin{array}{cc} 0 & \beta \\ 0 & 0 \\ \end{array} \right] \end{equation} \]

Σ

\[ \begin{equation} \left[ \begin{array}{cc} - \mu - \sigma & 0 \\ \sigma & - \gamma - \mu \\ \end{array} \right] \end{equation} \]

ngm.K_L

\[ \begin{equation} \left[ \begin{array}{cc} \frac{\beta ~ \sigma}{\left( \gamma + \mu \right) ~ \left( \mu + \sigma \right)} & \frac{\beta}{\gamma + \mu} \\ 0 & 0 \\ \end{array} \right] \end{equation} \]

Only E is a state-at-infection, so K is 1 × 1 and R₀ is its single entry:

states_at_infection(ngm), ngm.K
(Num[E(t)], Num[(β*σ) / ((γ + μ)*(μ + σ));;])
R0 = basic_reproduction_number(ngm)

\[ \begin{equation} \frac{\beta ~ \sigma}{\left( \gamma + \mu \right) ~ \left( \mu + \sigma \right)} \end{equation} \]

Numbers

Give parameter values as a Dict, pairs, or an ODEProblem built from the same system:

p = Dict(β => 0.5, σ => 0.25, γ => 0.2, μ => 0.01, N => 1000.0)
basic_reproduction_number(ngm, p)
2.2893772893772892

evaluate returns a numeric NextGenerationMatrix with the same fields:

num = evaluate(ngm, p)
num.K_L
2×2 Matrix{Float64}:
 2.28938  2.38095
 0.0      0.0
validate_decomposition(num)
true

R₀ > 1 exactly when the Jacobian T + Σ has an eigenvalue with positive real part:

(basic_reproduction_number(num) > 1, maximum(real, eigvals(num.T + num.Σ)) > 0)
(true, true)

A Catalyst model

With a reaction network the classification is read from the stoichiometry: a reaction is a transmission if it increases the number of infected individuals.

using Catalyst

rn = @reaction_network seir begin
    @parameters β σ γ μ N
    β / N, S + I --> E + I
    σ, E --> I
    γ, I --> R
    μ * N, 0 --> S
    μ, (S, E, I, R) --> 0
end
basic_reproduction_number(rn, [:E, :I])

\[ \begin{equation} \frac{\beta ~ \sigma}{\left( \gamma + \mu \right) ~ \left( \mu + \sigma \right)} \end{equation} \]

When there is no closed form

Three or more interacting types generally have no closed-form dominant eigenvalue.

@parameters q γ₃ C[1:3, 1:3] Nᵢ[1:3]
@variables Sᵢ(t)[1:3] Iᵢ(t)[1:3]
Cm, Nv, Sv, Iv = collect(C), collect(Nᵢ), collect(Sᵢ), collect(Iᵢ)
λ = [q * sum(Cm[i, j] * Iv[j] / Nv[j] for j in 1:3) for i in 1:3]
age = complete(System(
    [[D(Sv[i]) ~ -λ[i] * Sv[i] for i in 1:3];
     [D(Iv[i]) ~ λ[i] * Sv[i] - γ₃ * Iv[i] for i in 1:3]],
    t;
    name = :age))
ngm_age = next_generation_matrix(age, Iv; equilibrium = Dict(Sv[i] => Nv[i] for i in 1:3))
try
    basic_reproduction_number(ngm_age)
catch err
    err
end
NoClosedFormError("T has full rank, so the small-domain matrix is K itself")
contacts = [10.0 3.0 1.0; 3.0 8.0 2.0; 1.0 2.0 4.0]
vals = Dict{Any, Any}(Cm[i, j] => contacts[i, j] for i in 1:3, j in 1:3)
for i in 1:3
    vals[Nv[i]] = 100.0
end
vals[q] = 0.02
vals[γ₃] = 0.2
basic_reproduction_number(ngm_age, vals)
1.2625611542626114

Readable forms

The entries of K are products of transmission rates, mean sojourn times and transition probabilities. abbreviate names those quantities (τ_x for the mean time in state x, p_x_y for the probability of moving from x to y) so that the matrices read the way one would derive them by epidemiological reasoning:

ab = abbreviate(ngm)

\[\begin{aligned} x = \left[ \begin{array}{c} E\left( t \right) \\ I\left( t \right) \\ \end{array} \right] \\ T = \left[ \begin{array}{cc} 0 & \beta \\ 0 & 0 \\ \end{array} \right] \\ \Sigma = \left[ \begin{array}{cc} \frac{-1}{\mathtt{\tau\_E}} & 0 \\ \frac{\mathtt{p\_E\_I}}{\mathtt{\tau\_E}} & \frac{-1}{\mathtt{\tau\_I}} \\ \end{array} \right] \\ K = \left[ \begin{array}{c} \mathtt{p\_E\_I} ~ \beta ~ \mathtt{\tau\_I} \\ \end{array} \right] \quad \text{indexed by } \left[ \begin{array}{c} E\left( t \right) \\ \end{array} \right] \\ R_0 = \mathtt{p\_E\_I} ~ \beta ~ \mathtt{\tau\_I} \end{aligned}\]

basic_reproduction_number(ab)

\[ \begin{equation} \mathtt{p\_E\_I} ~ \beta ~ \mathtt{\tau\_I} \end{equation} \]

Your own names can be used instead; each definition is solved for one parameter, which is eliminated:

@variables R_E p_E
ab2 = abbreviate(ngm, [R_E => β / (γ + μ), p_E => σ / (σ + μ)])
basic_reproduction_number(ab2)

\[ \begin{equation} \mathtt{R\_E} ~ \mathtt{p\_E} \end{equation} \]

expand_definitions substitutes the definitions back, and numeric evaluation accepts values for either the original parameters or the abbreviations:

(expand_definitions(ab2, basic_reproduction_number(ab2)), basic_reproduction_number(ab2, p))
((β*σ) / ((γ + μ)*(μ + σ)), 2.2893772893772892)

Sensitivities, sojourn times and the effective reproduction number

The closed form can be differentiated with respect to every parameter:

elasticities(ngm)
Dict{Num, Num} with 4 entries:
  γ => (-γ) / (γ + μ)
  σ => ((β / ((γ + μ)*(μ + σ)) + (-β*σ) / ((γ + μ)*((μ + σ)^2)))*(γ + μ)*(μ + σ…
  β => 1
  μ => (-(γ + 2μ + σ)*μ) / ((γ + μ)*(μ + σ))

-Σ⁻¹ holds the expected times spent in each infected state:

mean_sojourn_times(ngm)

\[ \begin{equation} \left[ \begin{array}{cc} \frac{1}{\mu + \sigma} & 0 \\ \frac{\sigma}{\left( \gamma + \mu \right) ~ \left( \mu + \sigma \right)} & \frac{1}{\gamma + \mu} \\ \end{array} \right] \end{equation} \]

The effective reproduction number R_t is the same construction linearised at the current state rather than at the infection-free steady state, so it is a function of the uninfected states:

Rt = effective_reproduction_number(seir, [E, I])

\[ \begin{equation} \frac{S\left( t \right) ~ \beta ~ \sigma}{N ~ \left( \gamma + \mu \right) ~ \left( \mu + \sigma \right)} \end{equation} \]

It can be evaluated at a state, or along a simulated trajectory, or added to the system as an observed variable that the solver returns directly:

using OrdinaryDiffEqTsit5
seir_Rt, Rtvar = add_effective_reproduction_number(seir, [E, I])
prob = ODEProblem(seir_Rt, [S => 999.0, E => 0.0, I => 1.0, R => 0.0, p...], (0.0, 120.0))
sol = solve(prob, Tsit5(); saveat = 30.0)
sol[Rtvar]
5-element Vector{Float64}:
 2.2870879120879115
 2.133118916862721
 0.8624851258487862
 0.622853847143794
 0.8837021423881607

Building from T and Σ directly

If you already have the matrices (from a paper, say), skip the model:

@parameters b s g
ngm_direct = next_generation_matrix([0 b; 0 0], [-s 0; s -g]; infected = [:E, :I])
basic_reproduction_number(ngm_direct)

\[ \begin{equation} \frac{b}{g} \end{equation} \]
